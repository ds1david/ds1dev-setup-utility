# 04.1 — Toolchain MSYS2 UCRT64

**Requisito bloqueante:** MSYS2 instalado e UCRT64 validado.

## 4. Instalação de dependências Git, GCC, Autotools e build
```bash
pacman -S --needed \
  git base-devel \
  mingw-w64-ucrt-x86_64-toolchain \
  mingw-w64-ucrt-x86_64-autotools \
  mingw-w64-ucrt-x86_64-cmake \
  mingw-w64-ucrt-x86_64-ninja
```
Se solicitado, selecione todos os membros adequados do grupo toolchain. Confira `pacman -Si mingw-w64-ucrt-x86_64-autotools` e a disponibilidade do pacote. Git do MSYS2 é distinto do Git for Windows e do Git Linux.


Instalar pacotes via pacman após inspecionar versão e dependências; repetir não deve remover ou substituir ferramentas válidas.
